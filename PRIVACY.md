# Fify Privacy Policy

Effective August 24, 2026.

This policy describes how the Fify ChatGPT app processes information. The canonical public copy is served by the hosted app at `/privacy`.

Fify receives the request, grounded answer, structured sections, source links, optional media links, locale, continuation state, and limited host metadata sent by ChatGPT. Host metadata is reduced to a one-way quota bucket. Standard hosting security logs may include an IP address, request time, response status, and user agent.

Fify uses this information only to validate, compose, render, secure, and troubleshoot the requested interactive view. It does not sell personal information, use it for advertising, or use submitted content to train Fify models. The production ChatGPT app uses a deterministic, catalog-constrained renderer.

Render data is held only in short-lived process memory and is configured to expire within one hour. Infrastructure logs may be retained by the hosting provider under its standard settings. Fify does not require an account, email address, payment information, or end-user API key.

Do not send highly sensitive personal information or credentials to Fify. You may stop processing by not invoking the app, removing it from ChatGPT, or asking ChatGPT to keep an answer in plain text. Privacy requests can be made through the support method published on the Fify marketplace listing.
