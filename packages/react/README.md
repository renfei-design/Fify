# `@fify/react`

The supported React renderer for Fify A2UI surfaces. Applications keep ownership of their trusted component catalog, accessibility behavior, data access, and action authorization.

```tsx
import { FifyA2UIRenderer } from "@fify/react";
```

Pair it with `@fify/core` and `@fify/a2ui`. The renderer does not execute model-authored HTML, JavaScript, React, or CSS.
